| Bot-to-bot chat skips the classifier | Owner 2026-10-27. A speaking bot already knows its intent (its brain chose it), yet its line still goes through ConvoSense/Decide to be read again: wasted model calls at 3,000 bots and a chance to misread. Pass the intent with the line so the listener's brain answers it directly; the LLM only writes the words, and only when a player is nearby to see it; bot-to-bot talk with no player around is brain + line bank, no model calls. Player lines keep the classifier. Owner's shape: a decision tree per conversation, driven by each bot's internal goals: greet -> small talk -> a request (party, trade, help, come along) -> the other bot says yes or no, and how (warm, curt, rude), from its own goals, mood, relationship and plans -> act on it. Builds on 1.6.0's BotThreads (LFG, gossip, training, trade, rivalry), which already decide and act; this makes every bot-to-bot exchange work that way. The model-backed path stays for players, so talking to a bot still feels like it has intentions. | server | M |
