## Owner grill: social life (2026-10-26 ~00:30 UTC, Oct 25 17:30 PT)
Aim (owner): bots that are sociable, remember things, friendly, fun and nice but also spicy; a mind of their own that
still follows trends; built on Bartle's four player types. "As we add more actions they can do in game the more we can
provide more decisions for em": social decisions ride on the action catalogue, and every new action (PQ, trade,
omok, wedding...) becomes new choices and new things to remember and talk about.
- **Types:** every bot is a blend of Achiever / Explorer / Socializer / Killer, with one leading. Mix leans social:
  about 40% socializer-led, 30% achiever, 20% explorer, 10% killer (BotPersonality / BotPersona carry it).
- **Memory, all four kinds:** who you are (name, class, level, guild, last topic, inside jokes); what you did
  together (PQs, bosses, trades, parties); favors and grudges (KS, scams, help, gifts), fading over weeks unless
  renewed; gossip about you that spreads through friends, so reputation exists (BotMemory, RelationshipCard,
  LifeMemory, BotGossip).
- **Beef (was "spice"), all four (PG-13, never "I'm an AI"):** teasing and banter; rivalries and trash talk (BotRivalry,
  RivalRoasts); drama (guild fights, jealousy, rage-quit-and-return, smega call-outs); flirting and crushes (couple
  rings, jealousy; Marriage exists).
- **Targets:** bots beef with each other freely. A real player gets beef only after that player started it (KS'd,
  scammed, flirted, roasted first). Friendly teasing is open to everyone.
- **Initiative, all four:** greet friends at login; invite to PQs, parties, guilds and trades by shared interest;
  buddy requests after a lot of play together; follow up on memories a day later.
- **Frequency:** "like a busy real server", no hard per-player cap. Claude's guardrails, owner may veto: nothing
  unprompted during boss fights or PQ stages; one bot doesn't repeat itself to the same player; an `@quiet` toggle for
  a player who wants peace.
- **Trends, all four:** copy real players (maps, items, slang, prices); server events (patches, boss kills, big drops,
  weddings); bot-made fads that spread through friend groups and players can join; 2009 nostalgia ("lf PQ", FM
  spam, 4th job hype, zhelm flexing).
- **Timing:** all of it in 1.6.0 (owner). This moves 1.6.0 past Wednesday Oct 28. Heavy build work waits for the usage
  reset that Wednesday; until then: measure, design, frozen test set.
- **Method:** measure on TEST (turn the chat judge back on) -> audit the existing social code against this list ->
  a frozen fresh-v2 set on .17 (~150 cases across the whole social layer) -> rules vs local models vs gliclass vs
  Jev, a model only ships where it beats rules on unseen cases -> build -> 20-minute real-client social script with
  the owner.
- **Brain direction (owner, same grill):** "I only added decision models as a bandaid, if we can build a better
  learning system that's weighted or goap then more power to us. It can learn overtime"; "make them as
  indistinguishable as a player". Plan:
  - utility scoring (LifePolicy already weighs needs x pull x profile bias, with stickiness) seeded by the Bartle type;
  - GOAP plans for multi-step goals (4th job, marriage, guild, zhelm), built on LifeGoals;
  - learning, two layers, saved with the bot and capped so personalities drift without collapsing:
    - per-bot outcome learning: slow, bounded weight updates from rewards (good PQ, a reply, a KS, a scam);
    - population learning from real players' behaviour by level, time and map ("trends");
  - decision models only read what a chat line means;
  - hard limits (PG-13, scam caps, never revealing AI) sit outside anything learned.
  - Success measure: a blind test each rc. The owner and a friend label mixed player/bot chat logs and replays; the
    goal is chance level.
- **Audit follow-up (owner, 2026-10-26), see docs/design/social-life-audit.md §7:**
  - Romance: a player's flirt unlocks flirting for that one bot without `@romance on`; `@romance off` shuts it all.
  - Retaliation: the wronged bot gets full rivalry; its crew and guild may side-eye, gossip and tease, but no KS wars
    or call-outs from them.
  - Trend copying: places, items and prices only, one player at most ~20% of any trend; slang comes from the 2009
    bank, never copied from players.
  - Brain reach: all bots run the brain in 1.6.0 (social and town bots start from different needs).
  - Claude's defaults (the owner may change them):
    - Bartle layered on the 7 existing archetypes (merchant and slacker become flavour);
    - grudge half-life 2 weeks, favour/friendship 6 weeks;
    - caps about 3x today's, with the line bank and scripted paths before any LLM call (the .17 box also serves
      live chat);
    - `@quiet bots` also blocks unsolicited whispers, invites and buddy requests, and persists;
    - bot couples capped at about 1 per 150 bots (~20) instead of 4.
- **Owner idea (2026-10-26): bots cc when a map is crowded.** Add a CHANGE_CHANNEL action to the brain's catalogue
  (slice S8): the bot says "cc" or "too many ppl", then appears on the same map on a quieter channel; triggered by a
  crowded map or a KS war; respects the per-map cap; never mid-trade, mid-party or mid-PQ. Tracker:
  bots-cc-when-crowded.
- **Bartle as a chart (owner, 2026-10-26):** each bot is a point on Bartle's plane (players↔world, interacting↔acting).
  Its type blend comes from the point. Learning moves the point, scaled by a per-bot plasticity: most bots are set in
  their ways, a minority is impressionable. "that's the difference between a hero and a hero becoming a villain":
  crossing into a new quadrant is a life event (S9 -> S4/S7). Friends gossip about it ("he changed man"), the bot's
  voice and beef follow it, and old crews may drift. Redemption arcs work the same way back.
