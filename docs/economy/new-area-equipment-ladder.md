# Equipment progression alongside the imported-area balance

Companion to [the area balance plan](new-area-balance-plan.md). This is a proposed training and reward ladder,
checked against the retained server XML and repository recipes. No equipment stats, recipes, prices or drops
were changed. A level band is a recommended calibration band, not a new entrance rule. Actual installed loot,
client equipment support and player combat results remain unverified.

**Rebirth correction:** see [the full rebirth/forge audit](rebirth-and-forge-progression.md) and
[all 357 recipes](forge-catalog/full-list.md). Royal gear generally requires RB1, the level-140 class boss sets
RB2, and Japanese/AbsoLab/Arcane/Genesis RB3. Level alone does not unlock them. The tables below give equip
levels; every optional forged path is also conditional on its actual rebirth requirement. Crafted results
can carry substantial stats from consumed inputs, beyond these raw base values.

## Training baseline and optional upgrades

Use the cheaper path to calibrate ordinary enemies. Keep crafted/boss sets as rewarding alternatives and test
an upgraded character separately. Do not require a set from a region before a character can survive earning it.
All stages also need appropriate potions, accuracy, a usable main skill and affordable ammunition.

| Character level / intended ordinary training band | Proposed dependable equipment baseline | Optional progression |
|---|---|---|
| 100–119; classic reference and earliest imported maps | Level-90/100 class armour, level-95/100 weapon, modest ordinary scrolling; examples below | Existing classic boss accessories and stronger classic weapons if obtainable |
| 120–129; entry LKC/Rose/lower imported maps after combat calibration | Keep the classic weapon; start four Eclectic armour pieces (equip level 120) | Classic level-110/120 weapon or crafted legacy input, after checking its source |
| 130–139; middle imported tier | Four Muspell armour pieces plus class-correct Jaihin weapon (equip level 130) | Royal Von Leon (equip 130, RB1), conditional on affordability/material access |
| 140–159; later Future/Grandis maps at their intended level | Pensalir armour/cape plus Utgard weapon (equip level 140); allow previous-tier gear during acquisition | Lionheart / Dragon Tail / Falcon Wing / Raven Horn / Shark Tooth at 140/RB2; Japanese class sets at 150/RB3 |
| 160–179; deeper imported training | Upgraded Pensalir/Utgard; modest scrolling and consistent supply access | AbsoLab at 160/RB3; use as the stronger comparison profile, not an entrance requirement |
| 180–199; upper imported tier | Demonstrated attainable previous-tier gear; reference encounters must pass with that profile | Gradually acquired AbsoLab and class set bonuses; do not silently assume a full set |
| 200+ / rebirth tiers; Arcane and equivalent areas | Start from the prior tier's attainable profile and record actual HP/MP/build | Arcane Umbra at equip level 200/RB3; rebirth alone does not waive gear requirements or prove durability |

**The dependable path above is a design requirement, not a claim that it is dependable today.** Existing plans
classify Jaihin, Utgard and Pensalir as rare upgrades: selected ordinary rows have base chance 60 per million,
versus 800 for much common armour. At an assumed 4x drop rate, one particular 60 row needs about **4,167 eligible
kills on average**; 800 needs about **313**. At 1,500 eligible kills/hour these would be 2.78 hours versus 12.5
minutes, before spawn, damage, travel and inventory effects. Expected time is not a guarantee. A class can be
stuck with common armour and an old weapon. Repair weapon access before using the proposed next-tier weapon
as the balance baseline; otherwise continue calibrating against the older weapon.

Suggested acquisition budgets for review: a class-correct next weapon within one or two ordinary sessions
(target at most two hours), and its ordinary armour within roughly four to six hours total. These are proposed
budgets, not measured play times or approved rate changes. Prefer a targeted choice/exchange or explicit crafting
route with a reasonable ceiling over requiring every class to win the same random weapon lottery. Count the
materials' acquisition time and net mesos, and offer the upgrade from an earlier survivable tier.

## Stats, set bonuses and survival

These are **raw server values**, before randomization, scrolling, crafting transfers, buffs and sets. In the
retained data, The Beheader 1402035 has 139 PAD/MAD and ten slots, Jaihin two-handed sword 1402235 has 218 and
15 slots, Utgard 1402236 has 249 and 15, AbsoLab 1402260 has 321 and 20, and Arcane Umbra 1402259 has 444 and
25. This is already a substantial customized offensive ladder. Red Craven 1472053 also has 139 PAD/MAD;
remembered original-version weapon values would misrepresent this server. PAD/MAD equality in XML does not
make both stats useful to every job or mean every modern property is implemented.

Record primary/secondary stat requirements separately from level. For example, Jaihin two-handed sword needs
400 STR, Utgard 430, AbsoLab 480 and Arcane Umbra 600. Classic entry examples have zero raw stat requirements.
Do not budget a later item as equippable solely because the player has reached its level. Verify actual equip
checks and requirements on the installed client; scrolls/set bonuses must not create a circular equip dependency.

The custom server set catalog applies cumulative tiers. Useful totals below are **set bonuses only**, excluding
the individual items and scrolls:

| Equipped matching pieces | Verified catalog bonus relevant to the ordinary ladder |
|---|---|
| Four Eclectic | +7 relevant main stat and +7 PAD for physical families / MAD for mage; pirate gets STR and DEX |
| Four Muspell | +8 relevant main stat and +8 PAD/MAD; five with matching Jaihin additionally gives +10 all stats |
| Five Pensalir | +9 relevant main stat, +15 all stats, +9 PAD/MAD; six with matching Utgard additionally gives +10 PAD and MAD |
| Five class boss pieces | +20 all stats and +15 PAD (MAD for Dragon Tail) |
| Six class boss pieces, including matching weapon | +20 all stats and +45 PAD (MAD for Dragon Tail) |
| Two AbsoLab | +1,500 HP, +1,500 MP, +20 PAD and MAD |
| Five AbsoLab | +1,500 HP, +1,500 MP, +30 all stats, +95 PAD and MAD |

Mixing families does not earn the same bonuses. Pensalir/Utgard and class boss armour/weapon are alternatives,
not interchangeable set members. The boss sets list seven-piece bonuses, but a seventh piece generally needs
a shoulder beyond the five armour slots and weapon. Shoulder source, slot and client behavior need explicit
verification; the proposed baseline does not assume it. The table assumes the server actually loads the catalog;
missing/invalid deployed data can remove bonuses even when items exist.

Most early bonuses are offensive. Better gear can shorten exposure without making a low-HP character withstand
an excessive single hit. Do not solve ordinary monster damage by requiring late set HP, paid HP investment,
party HP buffs or a mage's MP pool on a physical class. Conversely, verify individual defensive properties
rather than ignoring them: the server XML for Pensalir Battle Helm has +150 HP/MP, Lionheart Battle Helm +300,
and AbsoLab's two-piece bonus is a large discontinuity. Test at zero, one and two AbsoLab pieces to detect a
survival cliff. Modern percent-HP, boss-damage, ignore-defence, potential and special upgrade flags need their
actual code/client behavior checked before including them in a combat budget.

## Shields, ammunition and shared accessories

- One-handed warriors: Maple Warrior shield 1092046 is a level-64 entry candidate. Compare the real combined
  weapon/shield result against two-handed weapons rather than requiring identical weapon attack.
- Magicians: Maple Magician shield 1092045 is a level-64 candidate; use a compatible shield only where the actual
  weapon/equip rules allow it. Prioritize INT/MAD and usable MP. Test Magic Guard with and without sufficient MP.
- Shadower: Maple Thief shield 1092047 at 64, then Dragon Khanjar 1092049 at 120 (raw +15 PAD, +2 LUK) is a concrete
  shield upgrade. Avoid making this optional rare piece the price of surviving normal training.
- Claw users: include stars in the loadout. Ilbi 2070006 has raw +27 PAD; accept cheaper supported stars for the
  baseline and log the actual stack. Gun users likewise need bullets; Shiny Bullet 2330004 is level 90, +18 PAD.
  Confirm recharge price, capacity and shop availability. Bow/crossbow users need the correct arrows or working
  Soul Arrow. Ammunition access is part of equipment progression.
- Shared upgrades: Zakum Helmet 1002357 (50, +15 all stats, +20 accuracy), Horntail Necklace 1122000 (120, +7 all
  stats), and Rex's Perfect earrings 1032102/3/4 (125) are explicit candidates to evaluate. They are optional
  boss/PQ/crafting paths with restrictions, not guaranteed starter rewards. A boss helmet competes with class
  set headgear, so recompute lost set bonuses before calling it an upgrade.
- Start other accessory slots with whatever supported affordable items the character actually owns. The repository
  has later rings, belts, pendants and face/eye recipes, recorded in the manifest. Their existence does not prove
  the material chain is obtainable. Keep Gollux/Sweetwater/Meister/dark boss items out of the minimum training
  profile until their acquisition and client compatibility have been established.

## Existing sources, costs and the access checks to run

The historical pool identifies eligible classic equipment, not the currently installed source table. Planned
050/055 rows provide explicit monster/item pairs; they are not migration receipts. For this equipment selection,
the retained manifests contain **1,249 planned rows across 392 named items** (many selected items have zero
planned rows). That does not establish that every selected item has a source. Exact rows, regions, base chances,
quantities and recipes are included in the evidence manifest.

| Equipment | Repository source evidence | Practical gap |
|---|---|---|
| Classic level-90/100 gear | Historical classic pool; some also have planned imported drops | Verify actual job-correct source and affordable acquisition before 100 |
| Eclectic | 114 planned rows in Future/Grandis; source mob levels 120–142 | Earliest training must allow players to earn it while still wearing classic gear |
| Muspell | 520 planned rows in Grandis/Future/Arcane; source levels 130–200 | Common armour alone does not establish a weapon path |
| Jaihin | 71 planned rows; source levels 130–200 | Ordinary rows include rare chance 60; introduce a dependable class-correct route or retain the old baseline |
| Pensalir / Utgard | 98 / 53 planned rows; source levels 140–200 | Both include rare rows; full-set completion can lag the intended tier |
| AbsoLab | 44 planned rows for the selected items; source levels 171–200, plus recipes | Drop sources come later than equip level 160; do not demand it to enter the maps that award it |
| Royal Von Leon / boss class sets / Japanese / Arcane | Explicit weapon and armour recipes | Trace each legacy input and material, fee, Maker level and transfer behavior; no planned row is not proof of no source |

The five armour recipes alone have these base fees, identical across the five family menus: Royal Von Leon
**1.055B mesos**, class boss set **1.725B**, Japanese set **2.845B**, AbsoLab **2.4B**, Arcane Umbra **3.77B**.
Weapons, material costs, reagents, stimulants and previous equipment are additional. At the earlier fixed-model
Sleepy Grobbler gross meso rate (13.55M/hour), even Royal armour alone represents about **78 hours** before
expenses or materials; this is an illustration using an assumed rate, not actual player earnings. These recipes
cannot be presumed to be a quick catch-up mechanism.

Recipe `requiredLevel` is a declared crafting value, while item `reqLevel` is the equip requirement.
The full forge audit found gaps in enforcement of declared craft/Maker levels; do not assume these are hard gates. Royal Von Leon
recipes generally say 120 versus equip 130, class boss 130 versus 140, Japanese 140 versus 150, AbsoLab 150
versus 160, Arcane 190 versus 200. Some recipes even specify level 1 (e.g. warrior AbsoLab cape and Arcane overall).
Do not treat those exceptions as level-1 equipment. Recipes also declare Maker levels and check materials; flagged legacy
inputs select an equipment slot, so inspect the actual transfer outcome instead of assuming a fresh blank item.

For each class, the next implementation batch should produce a small source sheet: chosen exact item IDs,
source map/monster/shop/recipe, minimum safe character level, effective chance or fee, expected and upper-bound
acquisition time, binding restrictions, stat requirements, and tested client support. Compare three loadouts:
previous-tier attainable gear, the proposed ordinary baseline, and the optional crafted set. Record survivability,
DPS, potions, ammo and net income with the same character. If only the optional crafted set survives, ordinary
monster tuning still fails the intended curve.

## Evidence and validation

Read-only extraction artifacts are under `/root/work/agent-runs/server/new-area-balance-codex/gear/`:
`items.csv` for review, `items.json` for full raw fields/recipes/planned source rows/set catalog entries,

`checks.json`. All 392 selected items have server data and a String.wz name. Five targeted snapshot assertions
checked customized weapon attack, the knuckle's job family, crafting versus equip level, and Royal armour cost;
the armour table's job masks were also checked during generation. These are offline evidence checks, not
regression tests or proof of in-game results.

This extension changes documentation only. No Java/Python runtime code, WZ, loot migration, craft recipe or
price changed. Maven and the client were not run. Active DB sources, friends' installed client data, actual
set loading and attainable acquisition times still need verification before implementing the proposed ladder.
