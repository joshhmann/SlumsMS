# The missing RB0 120–149 equipment bridge

Status: owner-approved loot/guide implementation is local; TEST/client/combat proof remains pending. Migration
061, Nimble's guide and a read-only source probe are implemented. No running server or WZ/base combat value was
changed. This extends the owner's existing 1.6.4 gear-progression ticket; it is not a deployment receipt.

## What the live rows establish

A SELECT-only export on 2026-11-03 contains 896 rows for the selected item scope. The saved-player comparison
already established that ten level-100+ non-GM characters belong to three accounts, all RB0. Some level-146–149
mages still equip Pyrope weapons. The comparison is a snapshot, not a death or EXP/hour trace.

- All exported Jaihin weapon rows have base chance 60 per million. At assumed 4x normal drops and 300 eligible
  kills/hour, one particular weapon averages 4,167 eligible kills / 13.89 hours, with about 31.98 hours to reach
  90% acquisition probability. This is on a correct source mob, before travel, combat or equip requirements.
- Jaihin Two-handed Sword 1402235 sources start at mob level 175; Jaihin Bow 1452237 starts at 167. Arcane sources
  add no ordinary RB0 route because that region requires rebirths. Reaching item level 130 does not make these
  sources suitable or accessible.
- Utgard Two-handed Sword 1402236 has one exported source: Angry Flyon 8642005 in Arcane, level 200, chance 60.
  Utgard Staff 1382245 has no exported row. The shared-item migration 059 does not repair this earlier tier.
- Armour and weapon supply differ: sampled Eclectic and Muspell ordinary armour rows are typically 800 per
  million, versus 60 for the rare weapon pool. A few common armour pieces do not establish a complete loadout.
- Some players already carry better weapons or a level-130 weapon they cannot yet equip. Supply changes need
  clear class/level/source guidance; do not attribute every weak loadout to RNG.

## Concrete proposal

The versioned [manifest](bridge-120-149.json) covers 113 existing items, all 16 supported weapon types and five
armour families. It adds no item IDs or rebirth unlock exceptions. All selected items passed retained-data
eligibility checks against the forge outputs and RB restriction lists.

| Farming start | Gear being earned | Proposed source mob levels | Expected entry equipment |
|---|---|---|---|
| 120 | Existing level-110 Dragon weapons; Dimon Wand for wand users; four Eclectic pieces per family | 113, 115, 120, 121, 122 | Existing classic weapons/armour; no forged gear or mandatory traces |
| 125 | Jaihin weapons + four Muspell pieces per family; equip at 130 | 123, 124, 126, 127, 129 | Entry gear / Eclectic |
| 130 | Utgard weapons + five Pensalir pieces per family; equip at 140 | 130, 132, 133, 135, 137 | Jaihin / Muspell as obtained |
| 140–149 | Finish the normal set; prepare for the existing Commerci-at-150 path | Same selected sources | Mixed previous/current gear allowed |

The wand exception avoids making Zakum's Poisonic Wand a normal drop. The level-110 Dragon weapons are reused
as proposed regional drops; existing boss sources remain intact. The retained items are not newly created.
Each selected weapon's actual job/stat requirements still apply, and client equipment support needs proof.

Each item has two selected source mobs among five per band, all from the existing lower-Grandis gate allowlist.
The tool verifies actual placements, positive EXP, source levels and non-boss/non-friendly/non-linked actors.
These checks establish candidate data/gate eligibility, not combat safety or a verified portal route.

**Exact proposed economy values:** 226 mob/item pairs, quantity 1, quest ID 0; weapon base chance 2,100 and armour
2,400 per million, inherited from the existing normal-gear policy. These are stored 1x chances; at 4x they become
about 0.84% / 0.96% per eligible kill. Mean eligible waits at 300 kills/hour are 23.81 / 20.83 minutes for a single
piece on its correct source. Two sources do not double a kill's probability. A seeded preview of 48 class-correct
loadouts (2,000 trials each) gives mean full-set ranges 0.81–1.12 hours for entry/Eclectic, 0.80–1.14 for
Jaihin/Muspell and 0.85–1.19 for Utgard/Pensalir; corresponding 90% completion ranges are 1.35–1.89, 1.35–1.94 and
1.37–1.97 hours. It uses the existing missing-item source-targeting model at 4x and 300 eligible kills/hour, excludes
travel/deaths/competition, and includes four/five armour pieces plus one correct weapon. It is an optimistic
acquisition preview, not the equal-rotation model or a measured session duration. Actual combat times remain open.

Against this export, 225 proposed pairs are absent and one already exists: Amethyst Tokka 2400004 → Eclectic
Moonsteed 1072960, chance 800. That pair needs an explicit ordinary-row floor of 2,400. **An insert-only migration
would silently leave it at 800.** Implemented migration 061 records original row IDs, old chances and quantities,
preserves quest-only pairs and stronger chances, and guards rollback against later edits or replacement IDs.
The live schema's unique pair key prevents adding an ordinary row beside a quest-only pair; such a collision is
preserved and fails the active-source QA check rather than converting a quest reward. The local export had none.
Apply/rollback only with game/drop writers stopped; the persistent intent journal supports interrupted reruns
even on MyISAM. Reconcile local migration number 061 with Server Dev; shipped 050/055 and candidate 059 stay intact.

Nimble's **Normal equipment guide** is behind `-Dslums.gear.bridge=true` (default OFF). It is a read-only
family → stage → item → two-source guide. It grants no equipment, mesos or warps. Generated JSON, NPC scripts,
the compatible jar and migration 061 must ship together. The switch is enabled only after sources are installed
and the drop cache is reloaded. HALF auto-QA `t-ng-10` verifies ordinary DB rates; `!qa run ng-10` supplies the
actual-client menu, equip/source and previous-tier combat checklist. It does not claim cache or combat proof.

## Combat remains a separate part of the bridge

The early Pantheon sources have retained raw server PA/MA 925/1,250. Skelosaurus's reference values are 530/670.
Those are attack stats, not damage per hit. Existing HP/EXP overrides already put Sleepy Grobbler at 71,500 HP
and 9,250 EXP versus Skelosaurus at 85,000 HP and 6,650 EXP. Replacing raw mob HP in a spreadsheet would therefore
misdiagnose this as a reward problem and miss the attack/client dimension.

Eclectic and Muspell mage armour have zero raw HP across all four pieces; Pensalir mage armour supplies 350 raw
HP across five pieces. These sets improve other stats, but cannot be assumed to fix a roughly 4,000-HP mage's
survival. Check set bonuses and Magic Guard/MP separately rather than adding an invented HP boost to the model.

No server-only PA/MA adjustment is proposed as a completed solution. Human incoming damage is client-reported,
and retained server/client attacks already differ elsewhere. The client lane must verify the 15 selected mob
profiles, including attack-specific fields, and the corresponding client/server changes must be tested together.
Keep gates/global rates unchanged. Leave harder Future maps as later destinations instead of treating every
level-120-accessible map as an introductory training map.
