Getting started

1. Get the launcher

SlumsMS is friends-only. Ask the owner for the launcher ZIP. The friends build already has the access key inside, so most people never have to type it.

Extract the whole ZIP somewhere you like and run SlumsMS Launcher.exe. It is Windows only (64-bit). The ZIP is not code-signed; you don't need to turn off your antivirus.

2. Install the game

The launcher checks your install when it starts and shows one button: Install, Update or Play.

  • Where it installs: the folder you pick in Settings; otherwise next to the launcher if the game is already there; otherwise %LOCALAPPDATA%\SlumsMS (no admin rights needed).
  • Size: the first install is about 23.6 GB (about 86,000 files). It resumes if it gets interrupted.
  • Updates only download the files that changed. Your config.ini is never overwritten.
  • Something broken? Settings → Verify and repair re-checks every file (slow, but thorough).
  • The launcher updates itself (from 1.3.0 on).

3. The access key

If the launcher says "This server needs an access key - enter it in Settings": open Settings (the gear), type the key the owner gave you under Access key, and press Save. The launcher checks again right away.

4. Make an account

There is no website sign-up. Type a new username and password on the login screen and the account is made for you. The password needs at least 6 characters. There is a limit of 3 accounts per internet connection, and a short wait between new accounts.

5. Play

Press Play. The launcher starts SlumsMS.exe, which opens the game with the SlumsMS client add-ons. The server address is already set; you never type it.

Streamers and Parsec users — the main display tip. If the game closes at start with error code: -2147467259, a virtual screen is your main display (Parsec, Sunshine, Steam Link, Virtual Desktop...). Make your real monitor the main display before you start the game. Or disconnect Parsec, start the game, then reconnect.

Where things are

  • Launcher log: %APPDATA%\mapleroot-launcher\launcher.log (handy for bug reports).
  • Game settings: config.ini in the game folder.

The launcher has no "server online" light yet. Say where friends should look for server status (Discord is planned, ticket 46).
