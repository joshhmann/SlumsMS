Friends only

How to join

SlumsMS is a small server for friends. You need an invite code from a friend who plays (or an admin), and then it takes about five minutes plus the download.

Five steps

  1. Get an invite code. Ask a friend who plays, or an admin. Each code makes one account and works for a while, so use it soon.
  2. Make your account. On the sign-in page, under “New here?”, type the code, a username (4 to 12 letters or numbers) and a password (6 to 12 characters, no spaces). The launcher's New account tab does the same. This is your game login too.
  3. Get the launcher. Ask an admin for it, and please don't pass it on. It's one small program with everything built in.
  4. Install. Press Install. The first download is about 23.6 GB and picks up where it left off if it's interrupted. If Windows or your antivirus warns you, see Getting started.
  5. Log in and say hi. Press Play and log in with the username and password from step 2. A short tour opens at your first login; type @guide to see it again.

Forgot your password later? Use Forgot your password? and an admin resets it. The game's login screen doesn't make new accounts any more; sign-up is only here and in the launcher.
