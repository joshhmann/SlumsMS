Sign in with your game account

Slums Street (the database) and the Slums Market are for players. You sign in from inside the game, so this website never asks for your game login.

How it works

  1. Get a code here. It's six letters and works for 10 minutes.
  2. Type it in game. Log in to any character and type @weblogin and the code in the chat box.
  3. Only type a code you got yourself. Typing someone else's code signs them in as you.
  4. That's it. This page notices within a few seconds and takes you on. You stay signed in for 30 days on this browser.
