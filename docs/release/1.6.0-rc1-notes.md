# SlumsMS 1.6.0-rc1 — TEST candidate notes

Draft for TEST review. Not a live release; no site, launcher-feed or Discord publication.

- Bots can choose training, real supply trips, town visits, helping friends and market work.
- Each bot has a personality blend and simple level/gear goals, saved across restarts.
- One activity starts at a time. Repeating an old request cannot start another copy of the trip.
- Friend requests get checked before a movement promise. Conversations and trades hold departures.
- GM `!botwhy <name>` shows the last real decision, its age, and the current phase/request.
- Current 1.5.1 fixes include conversation holds, NPC spacing, rally walk-ins and boss-run staging.

Shared actor and provisional weights stay as approved. Combat, reward rates, shop prices and economy caps are
unchanged. Selling uses existing hired-shop listings. PQ replies confirm readiness, not quest completion.
Fishing, medals and the daily dungeon are outside this candidate. Town movement, level mix, real-client pacing
and actual model voice still need review. A started restock trip does not prove a purchase.
