## Progression and tuning

Owner selected normal dropped gear through level200 using existing families, scrolling and accessories;
then forged progression through rebirths. Normal full-set target is1–4 active hours at the existing4x drop
rate. Every subsequent forge stage targets8–12 additional active hours. These are goals, not measured results.

| Stage | Minimum RB | Craft level | Fee per piece | Five armour + one weapon, incremental | Reference model hours |
|---|---:|---:|---:|---:|---:|
| Royal Von Leon | 1 | 120 | 5M | 30M | 11.00 |
| Class boss sets | 2 | 130 | 6M | 36M | 11.29 |
| Japanese class sets | 3 | 140 | 6.5M | 39M | 10.75 |
| AbsoLab | 3 | 150 | 7M | 42M | 10.33 |
| Arcane Umbra | 3 | 190 | 8M | 48M | 10.60 |
| Sealed Genesis weapon | 3 | 225 | 40M | weapon only; keep Arcane armour | 10.50 |
| Genesis weapon | 3 | 250 | 50M | weapon only; plus1M Fragment refining | 11.50 |

Craft levels do not override equip level/stat requirements or the recipe's Maker requirement. All five
families and16 weapon types use the same stage fees. Five armour plus one weapon through Arcane costs195M;
continuing to Genesis costs286M including Fragment refining, before optional enhancements. Accessories retain
existing recipes. No existing inventory is removed or recalculated. Equipment forged before this change
keeps its existing stats; HP/MP already lost by an older craft is not restored retroactively. Include such
characters in TEST comparisons rather than assuming every existing forged copy matches the new path.

The first four sets consume the corresponding previous piece plus regional ETC:100 per armour,200 each of
the first two regional items per weapon (900 total per full set). Arcane uses4 River Droplet Stones per
armour and8 per weapon (28 total). Armour has no boss/core requirement. Each set weapon adds one stage
boss trophy; from the class boss tier onward it also adds one matching class weapon core. Sealed Genesis
uses one token each from hard Lucid/Will/Darknell/Verus Hilla and one class core. Genesis uses one Monochrome
Void Core, one Tyrant Fragment, one existing Genesis Fragment and one class core.

The existing Genesis Fragment recipe is simplified to one of each of those four hard-boss tokens,1M mesos,
level225/Maker3. It was already one of the76 refining recipes; there is no new item or duplicate recipe.
Normal Lucid now awards one non-quest Butterfly Droplet Stone; hard Lucid awards two. These fixed clear rewards
do not receive the drop multiplier. Existing Lucid Matter awards remain.

The [stage policy](../economy/forge-stages.json), [exact238-recipe before/after diff](../economy/forge-economy-diff.csv)
and [357-recipe full list](../economy/forge-catalog/full-list.md) contain the complete numbers and IDs.
The [budget scenarios](../economy/forge-budget-scenarios.csv) assume300 eligible kills/hour,4x drops,
net income3/3.5/4/4.5/5/5/6M per hour by successive stage,30 minutes per boss clear and0.5 hours travel.
The reference model starts with no banked mesos. Funding and regional hunting overlap; boss/travel time is added.
Saved funds can shorten a stage substantially: regional hunting alone is about3 hours for the first four sets
and2.33 hours for Arcane under these assumptions. Income sensitivity±25% is included: slower
income can exceed12 hours. Boss eligibility, daily limits, party splits, combat and actual income need TEST
measurement before accepting these budgets. The [source contract](../economy/forge-source-contract.json) covers
38 main-chain material IDs; repository reward/placement evidence does not establish installed availability.

## Activation and packaging

The capability switches are `-Dslums.forge.coreexchange=true` and `-Dslums.gear.bridge=true` (both default false).
Enable the bridge guide only after migration061 and a drop-cache reload. Updated jar, NPC scripts and
recipe JSON must ship together. Existing forge corrections and recipe changes activate with their deployed
code/data. Loot activates only when its migrations are admitted/applied and the drop cache is reloaded.
No client artifact or speculative monster attack/stat change is included.
