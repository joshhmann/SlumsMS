## One-time nav cache clean-up (owner said yes, 2026-10-21)

Earned speed retires the old level tiers, so the old graph files would keep being re-baked nightly. Once, with the
game stopped, after deploying the 1.5.0 jar, in the server's working directory:

```sh
cd <Server>/cache/bot-nav
mkdir -p ../bot-nav-pre150 && cp -a . ../bot-nav-pre150/   # backup, delete after a quiet week
# graph files: keep only the base profile (speed 100, jump 100); bots rebuild what they use on demand
find . -maxdepth 1 -name '[0-9]*-s*-j*.bin' ! -name '*-s100-j100.bin' ! -name '*-s100-j100-ss.bin' -delete
# nightly deep overlay: drop the non-base keys of the current generation too (the next bake re-creates what is used)
find deep -type f -name '[0-9]*-s*-j*.json' ! -name '*-s100-j100.json' ! -name '*-s100-j100-ss.json' -delete
```

Learned player moves (`observed/*.json`) stay: they carry over to the new tiers by themselves on first load.
