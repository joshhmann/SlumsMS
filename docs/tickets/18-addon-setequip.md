# 18: SetEquipV3 addon

**Area:** Addons  
**Depends on:** -  
**Status:** shipped in v1.4.0 (server and client branch `addon-setequip`, via `test-rc4`)

## What

Server set data first (v83 has no SetItemInfo.img, so it must be written), then the client tooltip (merge into src/tooltip.cpp) and the stat window. Opcodes 0x371B/0x371C (superseded: 0x3726/0x3727, see Done). See the addon review.

## Done when

Set bonuses apply server-side and show in the tooltip.

## Done

- **Opcodes:** CP `SET_ITEM_ACTION` 0x3726, LP `SET_ITEM_SYNC` 0x3727, the SET_ITEM pair the client's `cashshopwnd.h`
  already reserves in its 0x372x block (even = request, odd = reply). The addon's 0x371B/0x371C were not used.
  Claimed in `/root/work/addon-opcodes.md`.
- **Data:** `src/main/java/soloMapling/SetEquip/set-items.yaml` (via `soloMapling.DataFiles`), generated by
  `tools/setequip/gen_set_items.py` from a later GMS `Etc.wz/SetItemInfo.img` (version hash 777), cut to this server:
  items its Character.wz has, not cash, a slot `EquipSlot` accepts, v83 weapon types, the item's own `setItemID`;
  only stats the server applies (STR, DEX, INT, LUK, AllStat, MaxHP, MaxMP, weapon and magic attack); tiers a
  character can actually reach. 297 sets (Von Leon, Empress, Bloody/Agares, Lionheart and the other Root-era
  boss sets, Tempest, Pinnacle, AbsoLab, Arcane Umbra, Maple weapon sets, job sets and more). Defence, accuracy,
  avoid, speed, jump, % HP/MP and potential options are dropped, so the tooltip only lists what is granted.
- **Server:** `server.setitem` (catalog, packets, `SetItems`), `SetItemHandler`; `Character#recalcEquipStats`
  adds the stacked tiers of every worn set (an item id worn twice is one piece; set INT raises magic like item INT);
  `equipChanged` pushes the worn pieces to real players. Bots get the bonus too, but no packets.
- **Client:** `MAPLEROOT_SET_EQUIP` (in `scripts/build.ps1`): two rows on the equip tooltip, a docked second tooltip
  with the pieces and tiers, and STR/DEX/INT/LUK/MaxHP/MaxMP added to the client's own cached totals (Ability
  window; MaxHP/MaxMP before Hyper Body, matching the server). Weapon/magic attack bonuses are server-side only:
  they count for bots, summons and the damage ceiling, not the client's own damage range.
- **Tests:** server `SetItemCatalogTest`, `SetItemPacketsTest` (golden bytes shared with the client's
  `tests/setitem_proto_test.cpp`), `SetBonusStatsTest` (through `reapplyLocalStats`).
