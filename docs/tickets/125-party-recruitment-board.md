# 125: Party / expedition recruitment board

**Area:** client + server
**Effort:** M
**Status:** open (proposed 2026-10-28, not scheduled)

Source: PlayKuro research (owner request 2026-10-28), Z:\MSv83\SlumsMS-dev\research-kuro\NOTES.md, section "Their Windows client". Ideas only: build it our way on slums.dll and our server; never copy their binaries, scripts or custom WZ assets.

## What

Create a recruitment with a goal (boss, PQ, map) and roles; others browse, apply, and the leader accepts.
Server holds the board per world; client window in the HUD. Bots can list and answer recruitments (fits the bot
social systems).

## Done when

Two TEST characters form a party through the board; a bot answers a recruitment.
